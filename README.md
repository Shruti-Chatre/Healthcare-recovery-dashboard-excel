# Healthcare Recovery & Hospitalization Analysis Dashboard (Excel)

## Project Overview

This project analyzes factors influencing patient recovery outcomes and hospitalization duration using healthcare data.

## Objective

* Analyze recovery and hospitalization trends.
* Build KPIs and Pivot Table analysis.
* Design an interactive dashboard.
* Generate actionable insights.

## Features

* Data Cleaning
* KPI Development
* Pivot Table Analysis
* Dashboard Visualization
* Trend Identification
